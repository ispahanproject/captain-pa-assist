# Captain PA Assist

機長アナウンス(日本語・英語)を、タイミングと状況を選んで組み立てるツールです。iPad(横向き)での使用を想定しています。

- 公開ページ: https://ispahanproject.github.io/captain-pa-assist/
- 個人が作成した非公式ツールです。日本航空の公式ツールではありません。
- 読み上げる前に、内容がその場の状況に合っているか必ず確認してください。

## 使い方(iPad)

1. Safari で公開ページを開く
2. 共有ボタン →「ホーム画面に追加」
3. 一度開いておけば、以後は機内モード(オフライン)でも開けます

新しい版を公開したあとにアプリを開くと、「新しい版が届きました」と表示されます。「更新する」を押すと新しい版になります(読み上げ中に勝手に切り替わることはありません)。今のバージョンは、フライト情報・設定のいちばん下に表示されます。変更点は [CHANGELOG.md](CHANGELOG.md) を見てください。

## 主な機能

- タイミング(出発前・上空・到着後・緊急)と状況を選ぶと、日本語・英語のアナウンス文を作成
- 自由作成:各状況で使っている文を選んで組み合わせる
- 作成した文の手直し(編集)と、読む前のチェック(重複・言い回し・時刻の言い方・未入力など)
- 便名を入れると、内蔵の JAL 時刻表から出発地・目的地を自動入力
  - 国内線 2026/9/1〜2027/1/4、国際線 2026/3/29〜2026/10/24(jal.co.jp の時刻表より。ダイヤ改正ごとに更新が必要)
  - 時刻表と違うときは空港を選び直すと、その便名は自分の登録が優先されます
- 外資系航空会社の機長がよく使う英語の定番フレーズ集(参考)
- 入力内容や設定は、その端末のブラウザの中にだけ保存されます

## 開発

`src/` の部品を `build.sh` でつなげて `index.html` を作ります。外部のライブラリやネット接続は使っていません。

```sh
sh build.sh
```

バージョンは `VERSION` ファイル(「1.1.0 2026-10-02」の形)で管理し、`build.sh` が画面の表示とオフライン用キャッシュの名前に入れます。リリースのたびに `VERSION` と `CHANGELOG.md` を更新し、GitHub のリリース(タグ v1.1.0 など)を作ります。

`index.html` は1つのファイルで完結しているので、ファイルを直接開いても動きます。`sw.js`・`manifest.webmanifest`・アイコンは Web で公開したときにオフラインで開くためのものです。
